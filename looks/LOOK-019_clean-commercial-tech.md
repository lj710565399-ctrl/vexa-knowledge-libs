# LOOK-019 · 干净商业科技

## ① 一句话质感
一切都被擦干净了：白得均匀、影子淡到几乎没有、材质纤毫毕现——不是冷酷的实验室，而是被精心包装过的、卖给你的未来。

## ② 胶片外观颗粒
- **色温/白平衡**：精准 5600K 中性白平衡，**白就是纯白**，无色偏（这是它和 LOOK-001 冷科幻最大的区别：001 偏青、019 中性）
- **调色**：高调（high-key）——整体亮度上抬，中间调集中在偏亮区间；饱和度自然偏低但**品牌色（可指定，如 VEXA 的霓虹青 #00FFCC）单独提纯**跳出画面
- **对比/黑位**：低到中对比，**黑位干净不抬**但画面里几乎不存在纯黑区域；高光柔和收住不 clipping
- **颗粒/噪点**：极细颗粒近乎无噪，数字级洁净——本卡是全库里唯一**主动弱化胶片颗粒**的（质感地板的颗粒项在此调到最低）
- **光晕/耀斑**：干净，无脏耀斑；仅金属/玻璃边缘出精确的细高光与一道克制的水平耀斑
- **镜头特性**：微距到中焦，**极高解析力**，边缘锐利无畸变；浅景深仅用于产品特写；无 vignette
- **打光**：大面积柔光箱包围式布光，多面补光把阴影削到极淡；轮廓靠背景分离与边缘高光而非阴影；桌面/地面做镜面反射托底

## ③ 可直接拼进提示词的关键词串
`高调干净布光大面积柔光箱包围、精准中性白平衡纯白不偏色、低对比无纯黑区域高光柔和不过曝、阴影极淡近乎无、金属玻璃边缘精确细高光、镜面反射托底、极高解析力边缘锐利无畸变、极细颗粒近乎无噪、品牌色单独提纯跳出`

## ④ 适用场景 / 触发
**适用**：晶核能量器的产品级展示镜头 / 企业总部大堂与走廊 / 全息发布会与演示界面 / 装备与道具的说明性特写 / 广告化插入段落 / 与地下黑市形成阶级对比的"上城"
**触发**：产品 / 广告 / 发布会 / 企业 / 总部 / 大堂 / 展示 / 极简 / 白色空间
**参考影片**：她（Her）· 极乐空间上层 · 苹果发布会视觉语言

## ⑤ 别和它混用
⚠️**本卡会主动压低质感地板的胶片颗粒项**——用它的镜头要显式声明"极细颗粒近乎无噪"，否则地板的"胶片颗粒"会和它打架，出来变成脏兮兮的伪商业片。
与 LOOK-001 冷科幻临床区分：**001 = 让人不安的干净（偏青、硬光、无菌）；019 = 让人想买的干净（中性、柔光、包装）**。同一栋大楼里，实验室用 001，展厅用 019。
