# FM-088 分镜拍摄手法提取

**「旁白讲计划·画面同步执行」**
- **原片片段：** 1995 年启德机场运钞车劫案（片中约 16:30–20:00）——策划者的粤语旁白一条条讲规则，画面直接拍劫案正在发生。
- **镜头序列：** 旁白「他们交接的位置有闭路电视，一定要想办法挡住」→ 插入监控画面（CAM 03 · 28.09.1995 THU 10:15:03）→ 蒙面人枪口顶住押运员 → 旁白「最多只有十分钟，因为押款员每十分钟向总部汇报一次」→ 对讲机特写「G27 汇报一下你那边的情况」→ 旁白「一旦没有回复，机场警队就会收到报警，不到两分钟就会赶来」→ 警车出库全景。
- **为什么有冲击力：** 旁白一直用将来时/条件句（要、一旦…就会、一定要），画面却拍正在发生，计划和执行压成同一条线；观众一边听规则一边看规则被破，2 分钟讲完一整场劫案，还站到了劫匪的上帝视角里。
- **可复用模板：** 主角定计划再执行的戏＝主角旁白逐条讲规则（每条一句，带数字：几分钟/几个人/几米）→ 每条规则配一个能拍的障碍画面（监控/对讲/门禁/守卫）→ 下一镜就是这个障碍被破 → 旁白最后一句「第一步就成功了」落在执行者的脸上。

**「大红字时间戳推进」**
- **原片片段：** 运钞全流程。
- **镜头序列：** 直升机落地 → 全屏大红字「9:30 AM」压在现金箱俯拍上 → 「9:50 AM」压在地勤装车 → 「10:10 AM」压在押运车进闸 → 「10:20 AM」压在警车库。
- **为什么有冲击力：** 每一步都钉死钟点，观众自动开始算时间，等于不用台词就给了倒计时；字比画面还大，节奏感像打拍子。
- **可复用模板：** 任务/倒计时类段落，每个节点一张全屏时间戳字卡（后期叠，提示词里不写字），间隔越来越短。

**「先报数字再给人脸」**
- **原片片段：** 押运车内。
- **镜头序列：** 车内三人中近景 + 旁白「一个司机，三个押款员」→ 「我查过他们的资料」→ 车头正面三人 + 「加起来工作经验不到两年」→ 全景四人下车 + 「四个新手押送两个亿」→ 主角车内特写，嘴角松一下：「这就是香港，永远会有惊喜给你」。
- **为什么有冲击力：** 用数字把对手缩成一张表（人数、年资、金额），再落到主角一张脸上，轻蔑和自信全在那一个表情里。
- **可复用模板：** 介绍对手/守卫时，旁白报 2–3 个数字，画面依次给对手，最后一镜落主角特写配一句态度台词。

**「货柜码头加速追车」**
- **原片片段：** 劫车后冲出机场货运区。
- **镜头序列：** 押运车穿货柜巷（低机位跟车）→ 蒙面司机「坐稳了」→ 水花溅起侧拍 → 警车甩尾 → 车速表指针过 139 km/h 特写 → 轮胎碾过铁丝 → 押运车撞破铁栏 → 警车扬尘停下 → 大远景押运车开出机场区。快切在 76–83 秒最密，一秒多刀。
- **为什么有冲击力：** 前 70 秒都是慢交代，这里突然加速，切点越来越密，用仪表盘和轮胎特写把速度变成可见的数字和物理。
- **可复用模板：** 逃脱段＝低机位跟车 → 一句「坐稳了」→ 仪表/轮胎/溅水特写交替 → 撞破障碍 → 大远景释放。

**「三方反应链收尾」**
- **原片片段：** 劫案得手后。
- **镜头序列：** 旁白「计划的第一步就成功了」→ 车里蒙面人摘手套 → 押运公司办公室，女人「怎么可能」、男人「到底怎么回事」、墙上挂钟、「这事会让我们公司完蛋」→ 抽烟的女人「接下来我就帮不了你了」→ 警察总部指挥中心全景 → 处长对讲「全港警队」。
- **为什么有冲击力：** 一件事的后果按 执行者→受害方→内鬼→最高权力 一层层往上抬，每层一两个镜头，观众感到事情越闹越大。
- **可复用模板：** 大事件得手后，按「我方 → 受害方 → 暗中有关的人 → 最高一级的追捕者」各给 1–2 镜反应，最后一镜落在最高一级。
