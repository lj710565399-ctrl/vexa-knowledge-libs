# LOOK-016 · 水下幽蓝焦散

## ① 一句话质感
水面把光切成一张不断游走的网，投在一切表面上；颜色被水一层层吃掉，只剩幽蓝，声音闷住，人的动作也慢了半拍——一个把观众按住呼吸的世界。

## ② 胶片外观颗粒
- **色温/白平衡**：强烈蓝绿色偏（水吸收红光），越深越蓝；近处人工光源可保留一点残暖形成珍贵的对比
- **调色**：单色倾向的青蓝绿主调，红色几乎消失（血在深水里是黑的，这是真实且有戏剧性的细节）；饱和度随深度递减
- **对比/黑位**：对比被水体散射压低，**远景发灰发雾**（水中"大气透视"极强）；黑位轻微抬起、带蓝雾
- **颗粒/噪点**：细颗粒 + **悬浮微粒**（marine snow）——无数小颗粒在光束里漂浮，这是水下最强的可信度信号
- **光晕/耀斑**：水面折射的**焦散网纹光斑（caustics）**在地面/墙面/皮肤上缓慢游走；光束穿过水体成可见锥形并轻微晃动；气泡出高光圆环
- **镜头特性**：广角（水下放大效应）；轻微色差与边缘软化；浅景深并不明显——雾比景深更负责分离层次
- **打光**：主光永远来自**上方水面**（自然）或摇晃的手持光源（人工）；光的方向与强度随水波不停变化，没有一帧是稳定的；人物下方为深蓝虚无

## ③ 可直接拼进提示词的关键词串
`水下幽蓝青绿色偏、水面焦散网纹光斑缓慢游走于表面与皮肤、上方射入的可见锥形光束随水波晃动、悬浮微粒marine snow漂浮、水体散射致远景发灰起雾、红色被吸收殆尽、气泡高光圆环、广角轻微色差与边缘软化、动作带水阻延迟感`

## ④ 适用场景 / 触发
**适用**：地下蓄水池/淹没层潜行 / 溺水与濒死 / 培养舱与液体维生装置（KAEL 续命场景的可选质感）/ 沉没载具逃生 / 需要"世界被隔开一层"的抒情段落
**触发**：水下 / 潜水 / 溺水 / 蓄水池 / 沉没 / 洪水 / 培养舱 / 液舱
**参考影片**：水形物语 · 深渊 · 阿凡达水之道（配 DIR-018 林奇超现实做梦核变体）
