# FM-089 动作打斗提取

**「坠入垂直车流」**
高耸入云的摩天大楼石质外檐被强风刮擦，下方是深不见底的垂直都市峡谷，几十层悬浮车流如同发光的湍急暗河在楼宇间穿梭，正午的阳光被切割成无数道刺眼的明暗光带。赤脚踩在狭窄石雕边缘的莉露被红白闪烁的警用悬浮车团团围住，探照灯将她的橘色头发照得发白。走投无路之际，她脚尖一点，身体如秤砣般向后仰倒，直直坠入深渊。耳畔风声呼啸，她穿过一层又一层疾驰的金属车流，下坠的速度越来越快，最终在刺耳的金属撕裂声与玻璃爆碎声中，整个人像炮弹一样砸穿了科本那辆明黄色出租车的金属顶棚，重重摔在后排包裹着人造皮革的座椅上。没等引擎黑烟散尽，红蓝爆闪的警车已经从四面八方包抄上来，科本猛拉方向盘，黄色车体在狭窄的空中车道里做出近乎九十度的垂直俯冲，撞开护栏，拖着一串电火花一头扎进下方阴暗潮湿、布满蒸汽管道的底层盲区，瞬间甩掉了头顶的追兵。

**「军火开箱教学」**
这是一间堆满报废工业机械的空旷仓库，灰暗的水泥地面上散落着铁屑，几束惨白的冷光从高处的天窗斜射下来，将空气中的浮尘照得一清二楚。佐格穿着剪裁考究的条纹西装，像捧着艺术品一样打开长条形手提箱，黑色的流线型ZF-1步枪在清脆的液压声中自动弹起、展开。他挂着绅士般的微笑，对着远处的塑料假人靶扣下扳机，先是一枪打偏，随后按下回放键，十几发追踪子弹带着尖锐的蜂鸣声在空中划出诡异的弧线，精准穿透假人的胸膛，碎塑料片四处飞溅。紧接着，枪管下方交替喷涌出刺眼的橙红火舌与惨白的极寒液氮，假人先是被烈焰吞噬，眨眼间又被冻成一尊挂满白霜的冰雕，在重力的拉扯下咔嚓一声碎裂满地。演示的最高潮落在那个不起眼的红色小按钮上，佐格顺手一指却没有按下，只留下一句轻描淡写的警告，让这件杀器在死寂的仓库里散发出令人毛骨悚然的寒意。

**「歌剧走廊肉搏」**
失落乐园号游轮的歌剧院内，幽蓝的舞台追光打在外星女高音高耸的蓝色皮肤上，而在一墙之隔的VIP包厢走廊里，暖金色的金属壁板与铺着红地毯的地面正沦为猎场。身材魁梧的孟加拉人佣兵端着重武器逼近，莉露赤手空拳立于走廊中央，随着舞台上咏叹调陡然拔高转为密集的电子鼓点，她原本松弛的肌肉瞬间绷紧。第一个佣兵扑上来的刹那，莉露侧身闪过枪托的砸击，右腿如钢鞭般高高甩起，脚背精准抽在对方厚重的下颚骨上，发出一声沉闷的骨裂闷响。她的动作快得拉出残影，在狭窄的过道里借着两侧金属墙壁腾空翻转，一记肘击砸弯了第二个敌人的鼻梁，顺势拧断其持枪的手腕，夺过武器反手一记重砸，将对方两百多斤的躯体硬生生砸进金属门板里，撞出一片凹坑与飞溅的电火花。所有的出拳、旋踢与舞台上的高音节拍严丝合缝，直到她被数把黑洞洞的枪口逼入死角，动作才在咏叹调落幕的瞬间戛然而止。

**「通风管重逢战」**
游轮客舱区的金属通风管道内一片漆黑，只有佐格手中武器瞄准镜发出的红点在狭窄的铁皮壁上晃动。莉露蜷缩在管道上方，透过格栅缝隙死死盯着下方，佐格察觉到头顶异响，毫不犹豫地抬起ZF-1对着天花板疯狂扫射。密集的子弹瞬间将薄铁皮撕扯得粉碎，火光与硝烟在幽闭的走廊里炸开，无数发穿甲弹穿透管道，在莉露身侧擦出刺眼的火星，最终一发子弹撕裂了她的皮肤，鲜血顺着银白色的金属管壁滴落。佐格甩下一枚闪烁着红光的圆形定时炸弹，转身扬长而去。就在莉露捂着流血的腹部从破碎的通风口跌落、奄奄一息之时，科本端着冲锋枪从拐角狂奔而至，迎面撞上留守的孟加拉人佣兵。没有半句废话，科本利用走廊立柱作为掩体，探身就是一串极其老练的点射，子弹精准咬进佣兵的眉心，沉重的尸体轰然倒地，他一把抱起血泊中的莉露，在警报红光的狂闪中冲向逃生舱。

**「游轮读秒引爆」**
失落乐园号金碧辉煌的大厅此刻已被刺耳的疏散警报和闪烁的红色警示灯淹没，大理石地面上满是逃难人群丢弃的杂物与翻倒的香槟塔。科本单手托着虚弱的莉露，另一只手端着抢来的重机枪，在散乱的掩体后与残余的孟加拉人佣兵展开对射。佣兵们依托二楼的环形栏杆倾泻火力，子弹将大厅的玻璃装饰柱打得粉碎，晶莹的碎碴如暴雨般落下。科本眼神冰冷，趁着对方换弹的半秒空隙，猛地从掩体后翻滚而出，枪口火舌狂喷，将两名佣兵从二楼栏杆上扫落，重重砸在赌桌上。当最后一名佣兵头目被逼入绝境时，科本一枪击毙了站在人质身后的他，极其嚣张地吹了吹枪口青烟。然而真正的死局在另一头的豪华套房内上演：佐格疯狗般冲回来关闭了自己设置的定时炸弹，刚松了一口气，躺在血泊中的濒死佣兵却咧嘴一笑，按下了胸口自带的微型核弹按钮，伴随着滴的一声轻响，刺目的白光瞬间吞没了佐格绝望扭曲的脸，整艘巨轮在深邃的太空中化作一团翻滚的巨大火球。

**「古墓神石激活」**
埃及古庙的密室完全由粗粝的黄褐色巨石砌成，没有半点现代光源，只有穹顶裂缝漏下的天光与四周火把跳动的暗红火苗，空气中弥漫着千年的尘土味。外面是逼近地球、遮天蔽日的终极邪恶黑球，密室内的众人正围着四座石柱疯狂打转，手忙脚乱地试图用各种工具撬开毫无反应的刻痕神石，急促的喘息声与石块的摩擦声交织在一起。转机出现在神父绝望中的一声长叹，微弱的气流拂过石面，风之石竟咔哒一声自行裂开，露出内部流转的微光。众人瞬间顿悟，科本一把抓起地上的黄沙狠狠撒向土之石，又将额头渗出的热汗抹在水之石上。只差最后的火之石，科本颤抖着掏出兜里仅存的一根火柴，在粗糙的石壁上猛地一划，微弱的小火苗在穿堂风中摇曳欲灭，他用宽大的手掌死死护住那豆火光，屏住呼吸将其凑近石柱。当火苗舔舐石面的刹那，四座石柱同时爆发出刺穿视网膜的金色强光，粗大的能量光束在石室半空交汇，将浑身颤抖的莉露包裹在中心，随着科本冲上去将她死死拥入怀中，一道足以撕裂苍穹的纯白光柱轰然冲破神庙穹顶，直刺太空中的巨大黑球，将其在无声的强光中彻底石化瓦解。
