# LOOK-014 · 监控低画质数字

## ① 一句话质感
画面不再是"摄影机拍的"，而是"某台机器记下的"——压扁的动态、爬行的噪点、掉帧的抖动、角落的时间码，观众立刻知道：这是被谁看着。

## ② 胶片外观颗粒
- **色温/白平衡**：故意**白平衡失准**——室内偏绿、夜视偏青绿或纯单色绿/白热，机器不会为了好看而校色
- **调色**：低动态范围，色彩挤在窄区间；高光死白、暗部糊成色块；轻微色偏（青绿或洋红）像廉价 CMOS
- **对比/黑位**：对比被压缩（不是高对比而是"信息不够"），黑位浮起带噪，高光大面积 clipping 无细节
- **颗粒/噪点**：**数字噪点而非胶片颗粒**——彩色斑点、暗部蠕动噪声、压缩产生的块状 macroblock 与拖影
- **光晕/耀斑**：强光源大面积光晕溢出与垂直 smear 拖尾（CCD 特性）；无优雅的镜头耀斑
- **镜头特性**：广角监控镜（超广、桶形畸变、四角失光明显），深景深全实，偶发自动对焦拉风箱与自动曝光呼吸
- **打光**：不打光——照单全收现场光，逆光就死黑、强光就过曝，这种"失败"正是可信度来源
- **叠加层**：扫描线/隔行撕裂、时间码与坐标 OSD、录制红点、偶发信号丢失的横向撕裂与马赛克，画面比例可用 4:3 或带黑边

## ③ 可直接拼进提示词的关键词串
`监控摄像头低画质影像、白平衡失准偏青绿、低动态范围高光死白暗部糊块、彩色数字噪点与压缩macroblock、垂直光晕smear拖尾、超广角桶形畸变四角失光、隔行扫描线与信号撕裂、时间码OSD叠加、自动曝光呼吸`

## ④ 适用场景 / 触发
**适用**：PHARAOH-0 清扫单位的机器视角 / VEXA-09 护目镜 HUD 第一人称 / 黑进监控看回放 / 无人机侦察画面 / 反派监视主角的插入镜头 / 被"看见"的紧张感建立
**触发**：监控 / 摄像头 / HUD / 护目镜视角 / 机器视角 / 黑客 / 录像 / 无人机
**参考影片**：谍影重重监控段 / 索命之地 / 第九区（配 ACT-023 跑酷追逃的第一人称更晕眩）

## ⑤ 别和它混用
它是**插入镜头专用**，不是整场基底——一场戏里通常只有 1–3 个镜头切到机器视角，其余仍走该场原本的 LOOK。整场都用会让观众失去情感代入（机器没有情绪）。⚠️与「质感地板」的毛孔级皮肤/物理 cine 镜头**天然冲突**，用本卡的镜头要显式声明覆盖地板的写实摄影项。
