# LOOK-005 · 惊悚幽闭暗调

## ① 一句话质感
大片黑暗吞掉画面、只剩一束冷光劈开轮廓、暗部浮着不安的噪点——看不见的地方才是威胁，恐惧来自缺席的光。

## ② 胶片外观颗粒
- **色温/白平衡**：冷 4000K 偏青绿，病态的荧光/月光冷调
- **调色**：极低饱和近乎单色，青绿或钢蓝一条冷线，红只在血/警报时刺出
- **对比/黑位**：极高对比，黑位死沉压到纯黑，大面积欠曝，主体只留一道边缘光
- **颗粒/噪点**：暗部刻意的高 ISO 噪点/颗粒，制造"看不清"的焦虑
- **光晕/耀斑**：单一光源的硬边光刀、手电/应急灯扫过的移动光、幽微冷光晕
- **镜头特性**：中长焦压缩空间制造逼近感，浅景深让黑暗背景彻底虚掉藏东西，偶尔广角低角度失衡
- **打光**：单光源低调布光（low-key），侧光/底光/背光勾一条边，其余全黑，光比极大

## ③ 可直接拼进提示词的关键词串
`低调布光单冷光源、极高对比大面积欠曝纯黑黑位、主体只留边缘轮廓光、暗部高ISO噪点颗粒、青绿病态冷调、浅景深黑暗背景吞没、硬边光刀移动手电光、幽闭逼近恐惧感`

## ④ 适用场景 / 触发
**适用**：潜行 / 被清扫单位追杀 / 停电幽闭走廊 / 未知威胁逼近 / 悬疑揭示前的压抑（VEXA-09：废弃区深层、PHARAOH-0 巡猎段）
**触发**：惊悚 / 恐怖 / 潜行 / 黑暗 / 幽闭 / 追杀 / 怪物 / 悬疑
