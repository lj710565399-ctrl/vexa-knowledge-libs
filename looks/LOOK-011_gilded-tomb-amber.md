# LOOK-011 · 古墓鎏金琥珀

## ① 一句话质感
火把的活体暖光舔过石壁浮雕，金饰把光反弹成一层琥珀色的空气，尘埃在光柱里浮游——古埃及地宫的呼吸感，暖而不甜、旧而有重量。

## ② 胶片外观颗粒
- **色温/白平衡**：低色温实用光（1800–2500K 火焰）打底，白平衡略偏冷校正，让火光在画面里真的"橙"起来而不是糊成一片黄
- **调色**：琥珀-青蓝双色分离——高光与中间调走蜜色/鎏金，阴影拉向石头的青灰与深褐，避免整幅泛黄发腻
- **对比/黑位**：高对比但黑位微微抬起（lifted black），墓室深处不是纯黑而是有沉积的暖灰，保留"空间还在往里延伸"的信息
- **颗粒/噪点**：中偏粗胶片颗粒，暗部颗粒明显，配合石材质感做旧，像 35mm 推感光
- **光晕/耀斑**：火把亮部轻微暖 halation 与摇曳的光溢出；金器高光出细星芒；空气中悬浮尘埃形成可见的体积光柱（god rays）
- **镜头特性**：中焦为主（35–50mm）保留石壁的纵深与浮雕曲率，中等光圈保证象形文字纹理清晰；轻微老镜低反差与边缘失光（vignette）
- **打光**：全部动机光——火把/油灯/裂缝天光，单一主光低位侧打让浮雕投出长而硬的凹凸阴影，金面做反弹补光，人物永远一半在暗里

## ③ 可直接拼进提示词的关键词串
`火把琥珀暖光低位侧打、石壁浮雕长凹凸阴影、鎏金反弹补光与细星芒高光、空气尘埃可见体积光柱、琥珀与青灰双色分离、高对比暖抬黑位、中粗胶片颗粒、边缘轻微失光、古墓潮冷厚重空气感`

## ④ 适用场景 / 触发
**适用**：废弃区第七层地宫 / 神殿祭坛与晶核揭示 / 象形浮雕解读戏 / 墓道潜行 / 与古埃及遗产相关的一切揭秘时刻（VEXA-09 世界观的"古"侧底色，与霓虹侧 LOOK-002 互为两极）
**触发**：古墓 / 墓室 / 神殿 / 祭坛 / 火把 / 象形 / 浮雕 / 遗迹 / 黄金
**参考影片**：木乃伊系列 · 夺宝奇兵 · 国家宝藏（配 DIR-003 维伦纽瓦的巨物尺度更压迫）

## ⑤ 别和它混用
与 LOOK-002 霓虹雨夜互斥——同一场里二选一。若剧情要"从霓虹街区走进古墓"，正确做法是**分镜换卡**：街上用 002、跨过门槛后切 011，光色反差本身就是叙事。
