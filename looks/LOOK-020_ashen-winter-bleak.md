# LOOK-020 · 末日灰烬冷寂

## ① 一句话质感
天是一块没有太阳的灰板，灰烬和雪分不清哪个是哪个，颜色像被这个世界一起放弃了——不是危险，是更彻底的东西：没有希望。

## ② 胶片外观颗粒
- **色温/白平衡**：冷而**无光源方向**（全阴天/散射），色温偏冷但不蓝——是那种"灰得发青"的无色感
- **调色**：极度去饱和（保留 10–20% 饱和度即可），全片压向灰绿-灰青；**唯一允许的颜色是血、火、或角色身上的一点标志色**，因其稀缺而刺眼
- **对比/黑位**：**低对比**，动态范围被压扁到中间调，黑位抬起呈灰——世界没有强光也没有真正的黑，只有无穷的中灰（与 LOOK-013 黑白的极端对比正相反）
- **颗粒/噪点**：粗颗粒，且在大片灰色天空区域**颗粒最为可见**，加重廉价与破败感
- **光晕/耀斑**：无耀斑（没有直射光源）；只有雾/雪造成的整体 veiling glare 让远景一层层褪成白
- **镜头特性**：中长焦压缩让人物在荒原中显得渺小且无处可去；深景深；轻微失光；不要漂亮的浅景深——浅景深会让画面变"美"，与本卡的意图冲突
- **打光**：**全散射无方向**，天空即唯一光源，顶部微弱下压，人物眼窝略暗、面部平；不给轮廓光（轮廓光=希望，此处不给）
- **落物**：灰烬/细雪缓慢飘落，在深色背景前才可见，是本卡最重要的动态元素

## ③ 可直接拼进提示词的关键词串
`全阴天无方向散射光天空即唯一光源、极度去饱和压向灰绿灰青、低对比中间调压扁与抬起的灰黑位、不给轮廓光面部平淡、灰烬与细雪缓慢飘落于深色背景前可见、粗颗粒在灰天空区域尤为明显、中长焦压缩人物渺小、远景veiling glare层层褪白、唯一饱和色仅存于血或火`

## ④ 适用场景 / 触发
**适用**：战败后的废墟行走 / 同伴死亡与葬礼 / 补给耗尽的绝望赶路 / KAEL 倒计时归零前的至暗时刻 / 全片情绪最低点 / 需要让观众"陪着角色一起没力气"的段落
**触发**：末日 / 灰烬 / 雪 / 阴天 / 荒凉 / 废墟 / 绝望 / 死寂
**参考影片**：末日危途（The Road）· 潜行者 · 1917 阴天段（配 DIR-003 维伦纽瓦的空旷尺度更绝望）

## ⑤ 别和它混用
与 LOOK-004 沙尘废土同为"废土"但情绪相反：**004 是烈日高对比的"残酷但活着"，020 是无光低对比的"活不下去了"**。判据看剧情能量：还在拼→004，已经垮了→020。
本卡是全库**情绪最低**的一张，用完之后下一场若要回暖，LOOK-017 晨雾柔光是最自然的接续（灰→柔白，反差不突兀但情绪已翻转）。
