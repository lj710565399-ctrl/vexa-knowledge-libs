# 打戏规则（/fenjing 视频提示词用）

来源：higgsfield-fight-scene v2.4（截拳道 / 咏春编舞，英文原文在本目录 SKILL.md + references/）。2026-10-29 用户要求存进库。
/fenjing 只在本批场次有打戏时注入「通用」节；剧本或方向里点名截拳道/李小龙、咏春/叶问时再加对应流派节。
⚠️ 和原 skill 的一处差别：原文要求罕见招式配「生活类比」（像关抽屉、像网球反手），/fenjing 禁比喻，所以改成写清 击打面 + 掌心朝向 + 受击方向。

## 通用（任何打戏）

- **拍子**：一拍 ≈ 1–2 秒，一拍只有一个动作。8 秒的镜头最多 4–6 拍，其中 1–2 拍是站定/停顿。一场交手 2–4 拍分出胜负，不堆连招。
- **每一拍四件事**：站位 → 动作（哪只手/脚、什么路线、打哪里）→ 对手身体怎么反应（顺着打击方向：反手横抽＝头往侧边甩，直拳＝头往后仰）→ 新站位。没写反应，模型会打空。
- **开头一帧写身体几何**：第一帧把架势写成身体几何（侧身/正对、哪只脚在前、后脚跟抬不抬、前手在什么高度、重心在哪），之后每段用同一句话复述，不写流派术语（模型不认识术语，会画成通用功夫片）。
- **只写正向约束**：写「每一脚都在腰带以下」「手臂第一个可见的动作就是这一拳本身，从护手的位置直接打出」，不写「不要高踢」「没有蓄力」（写出来的被禁动作反而会被画出来）。
- **停顿是打法的一部分**：爆发 → 完全静止 → 爆发。静止写成状态：「他回到侧身架势，一动不动」。
- **罕见招式三要素**：写清击打面（拳背/掌根/脚掌外沿先碰到）、掌心朝向、受击方向。
- **机位**：侧身架势和直线拳在侧面或四分之三侧面最清楚；有踢腿的镜头要让腿入画（写「双脚入画，两人全身在画里」），不能是胸口以上的近景。决定性的那一下用长时间固定远景，靠动作本身的速度，不靠剪辑。
- **把对手打飞要先写落点**：撞到哪个箱子/门/墙。
- **声音**：每一下打击的声音写进「声音」行（拳打在下巴上的闷响、脚踩膝盖的脆响），不写就没声。
- **一次交换＝一个镜头**；要剪，就剪在静止停顿那一拍上。
- **打法锁定句**：同一场的打戏单元，「人物表演」末尾逐字带同一句「打法：……」（写这场的架势几何 + 打法节奏，20–40 字）。

## 截拳道（剧本/方向点名 截拳道 / 李小龙 / JKD 时加）

- 架势：侧身，强侧手脚在前，脚距略宽于肩，后膝弹性弯曲、后脚跟抬起，重心在前脚掌、轻轻弹动，前手半伸在肩高，后手贴下巴，下巴收。
- 核心＝截击：对手刚开始抡拳，主角的前手拳已经先打到；对手那一拳停在半路。整场至少一次截击。
- 最长的武器打最近的目标：前手打脸，前脚踩膝盖/小腿。
- 防守和打击是同一个动作：一只手拨开来拳，另一只手同时打中。
- 步法轻、像击剑：小推步前后，不交叉脚；后退走斜线，不直线后退。
- 主角表情平静，前后几乎不动，暴力是两段静止之间的一闪。
- 常用段落：P1 截一击（对手大摆拳 → 前手直拳在他蓄力时打下巴 + 上步 → 对手踉跄 → 静止，4–6 秒）；P2 先踩膝再接拳（6–8 秒）；P5 一打二：走位让两个对手排成一线、先放倒近的那个，分两个镜头。

## 咏春（剧本/方向点名 咏春 / 叶问 时加）

- 架势：正对对手，双脚窄、脚尖微内扣、膝盖向内夹，重心沉在骨盆；双手叠在胸口中线上，一只半伸指尖朝前，一只收在胸骨前；肘沉、贴肋。
- 节奏和截拳道相反：持续施压、贴身不放，连环直拳每秒三四下，小平步一路逼进，直到把对手顶上墙。
- 拳从胸口中线直出，拳眼朝上，打完回到胸骨；腿是正前方用脚掌直踩大腿。
- 黏手：手腕搭在对手前臂上，随对方每一下抖动走。
- 掌根击下巴、肘从架子里斜劈锁骨、一手把对手手腕往回拽同时另一手掌根迎上去（两个速度相撞）。
- 木人桩训练戏：前臂敲木头、手掌拍、低踢撞桩腿，节奏稳定、偶尔断一下再起。
