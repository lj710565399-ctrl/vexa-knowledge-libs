# LOOK-017 · 晨雾柔光

## ① 一句话质感
太阳还没真正升起，光是从雾里渗出来的——没有阴影的锐边，没有饱和的颜色，一切都轻，适合放下一件事或告别一个人。

## ② 胶片外观颗粒
- **色温/白平衡**：中性偏冷（5500–7000K）带一丝晨曦的淡粉/淡金，**绝不橙**——橙是黄昏，粉白是黎明，这是两卡的分界
- **调色**：整体低饱和，只留天空的淡青与皮肤的淡粉；绿植偏灰绿；高光柔和不刺眼
- **对比/黑位**：**低对比**，黑位明显抬起呈灰蓝（雾的散射），这是本卡最反直觉也最关键的一项——不要为了"好看"把黑压下去
- **颗粒/噪点**：细而柔的颗粒，均匀分布，像柔化过的中速胶片
- **光晕/耀斑**：大面积柔和 bloom；逆光时整个画面轻微起雾（veiling glare），高光边缘晕开；允许一道低角度长耀斑
- **镜头特性**：长焦（85–135mm）压缩前后景，让雾成为一层层的隔板；大光圈焦外化成极柔的奶油质地；可加轻微柔焦/黑柔滤镜
- **打光**：单一低角度逆光/侧逆（初升的日）穿过雾成为柔性大面积光源，人物几乎全靠边缘光成形，正面只有雾提供的环境光，光比极小

## ③ 可直接拼进提示词的关键词串
`黎明晨雾柔性大面积逆光、低对比与抬起的灰蓝黑位、整体低饱和仅留淡青与淡粉、雾层层分隔前后景、长焦压缩与奶油柔焦外、大面积柔和bloom与veiling glare起雾、细柔均匀颗粒、极小光比无锐边阴影`

## ④ 适用场景 / 触发
**适用**：一场恶战之后的清晨 / 告别与目送 / 和解与承诺 / 疗伤与静默相处 / 单集或整季的收尾镜头 / 需要"情绪落地"的任何时刻
**触发**：黎明 / 清晨 / 日出 / 雾 / 告别 / 和解 / 平静 / 结尾
**参考影片**：银翼杀手2049 结尾 · 卧虎藏龙竹林晨雾 · 廊桥遗梦（配 DIR-001 王家卫的凝滞时间更绵长）

## ⑤ 别和它混用
与 LOOK-003 暖调回忆常被混淆——**003 是"过去/回忆"（暖橙、加了滤镜的记忆），017 是"当下/放下"（冷粉、真实的此刻）**。判据：这场是在回忆里，还是在现实的早晨？选错会让观众误以为在闪回。
